# MH-002 · 베트남어 입력 준비와 NFC 계산 근거

기록일: 2026-09-30 · 실행자: Harness 입력·채점 개발 에이전트

**판정: Telex/VNI 실제 OS 입력 수용은 Blocked. NFC·문자 단위·산식 검사는 통과했다.**

이때 Blocked는 **베트남어 지원 기능이 빠졌다는 뜻이 아니다.** 베트남어 문자열 입력을 받아 성조를 보존하고 NFC 동등성을 비교하는 기능은 구현했다. 남은 검사는 실제 Windows Telex/VNI에서 키를 눌러 조합·성조 수정·확정·취소를 할 때 앱이 해당 문자열을 안전하게 받는지 확인하는 호환성 검사다. 일반 문자열 대입이나 합성 이벤트 통과로 이 부분까지 확인했다고 말할 수 없다.

연결: [MH-002](../tickets/MH-002.md), [MH-008](../tickets/MH-008.md), [D003](../D003-input-scoring.md), [T001](../T001-validation-plan.md), [공통 환경과 입력 정책](MH-001-ime.md)

## 구현과 검사 범위

- [관찰 프로브](../../public/ime-probe.html)에 베트남어 `chào → chao → chào`, 영어 `cat / Cat / cat. / cat  dog`, 분해형 `cha\u0300o` fixture를 준비했다.
- [순수 채점](../../src/scoring/index.ts)은 `strict-nfc-v1`, `scoring-v1`을 구현한다. NFC 후 앞뒤 U+0020만 제거하고 성조·대소문자·구두점·내부 공백·그 외 공백을 보존한다.
- 확장 자소 군집은 `Intl.Segmenter`로 계산한다. 미지원 환경에서는 명시적 오류를 내며 UTF-16 길이로 대체하지 않는다.
- 정확도는 군집 Levenshtein 거리로, 속도는 제출 군집 수/경과 시간으로 계산한다. 비정상·너무 짧은 시간, 도움 입력, 중단, 알 수 없는 입력 방식은 비교에서 제외한다.
- 의미 첫 답은 재시도로 덮어쓰지 않고 힌트 노출별 분모를 분리한다. 비교 키에는 언어·입력 방식·기기·OS·브라우저·콘텐츠 개정·첫 시도/재시도·산식 버전을 포함한다.
- 입력 문자열 자체를 장기 저장하는 책임은 이 모듈에 없다. 반환된 확정 문자열은 일시 채점용이며 영구 저장에는 집계 결과만 전달해야 한다.

## 실행 결과 · 계산 및 합성 이벤트

공통 런타임과 기준 소스는 [MH-001 기록](MH-001-ime.md)을 따른다.

```text
npm test -- tests/input.test.tsx tests/scoring.test.ts
Test Files  2 passed (2)
Tests       42 passed (42)
Duration    1.76s
```

| fixture / 경계 | 실제 계산 결과 |
|---|---|
| `chào` / `cha\u0300o` | NFC 후 정답, 4군집 |
| `chào` / `chao` | 성조 차이 오답 |
| `가` / `\u1100\u1161` | NFC 후 정답 |
| `가` / `ㄱㅏ` | 호환 자모를 임의 변환하지 않아 오답 |
| `한글` / `한굴`, 4초 | 정확도 50%, CPM 30, 오답 |
| `xin chào` / `xin chao`, 16초 | 정확도 87.5%, CPM 30, 오답 |
| `cat` / `cats`, 8초 | 정확도 75%, CPM 30, 오답 |
| 공백뿐 제출 | 점수·시도 결과 없음 |
| 0·음수·NaN·무한 시간 | CPM null, 비교 제외 |
| 999ms·도움·중단·unknown | 각각의 비교 제외 사유 유지 |
| 반올림 정확도 100.0%, 실제 문자열 불일치 | 정답 false 유지 |
| 의미 첫 오답 → 재시도 정답 | 첫 오답·힌트 노출 기록 유지 |

위 결과는 문자열 fixture를 통한 프로그램 계산이다. 입력기 키열의 조합·숫자/성조 변환·후보창 동작을 검사하지 않았다.

## 실제 입력 환경의 미실행 상태

`Get-WinUserLanguageList`의 확인 결과는 **ko, en-US**였다. 베트남어 Telex/VNI가 사용자 언어 목록에 설정됐다는 근거가 없다. 이 결과만으로 시스템 전체 입력기 설치 여부를 단정하지 않으며, 설치·언어 설정은 이번 실행에서 변경하지 않았다.

## 현지 검수 절차

1. 사용자가 준비한 실제 Telex/VNI 환경과 실행 브라우저·입력기 버전·키보드를 기록한다. 설치나 OS 설정 변경은 별도 범위로 다룬다.
2. Telex의 `c h a o f`, VNI의 `c h a o 2`는 **시험 후보 키열**이다. 실제 설정에서 만들어진 결과와 이벤트를 기록한다.
3. 성조 변경·Backspace·선택 교체·Tab/클릭으로 포커스 이동을 수행한다. composition 이벤트가 없는 변환도 beforeinput/input/DOM 전체 값으로 관찰한다.
4. 확정값이 `chào`를 유지하고 `chao`와 구분되는지 확인한다. 분해형 문자열 대입 실험은 실제 키 입력 로그와 별도 표시한다.
5. 고정 fixture 로그와 예상·실제 결과를 남긴 뒤 지원 정책을 결정하고 MH-016에서 앱 통합을 다시 검사한다.

독립 콘텐츠·번역 검수는 수행하지 않았다. fixture는 검수 완료 교육 문항을 의미하지 않는다.
