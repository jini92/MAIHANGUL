## 버전·출처·상태

- 최초 원고는 모든 개념 `revision=1`이었다. 독립 기술 검수에서 모두 `revision=2`로 수정했고, 베트남어 첫 단계 풀이를 보완한 현재 원고는 C001~004 `revision=3`, C005~020 `revision=2`다. 묶음은 계속 `packId=MH-CORE-01`, `packVersion=null`, `schemaVersion=1`이다.
- 각 개념의 provenance는 AI 보조 작성 방식·실제 작성일·빈 외부 출처 목록·장부 ID `MH-R001-TEXT`/`MH-R002-TRANSLATION`을 기록한다.
- 교육·KO·EN·VI·권리의 모든 검수 상태는 **draft**, 담당자·승인일·증거는 **null**이다. 별도 검수 팀의 자동 코드 검토를 언어 전문가 승인으로 치환하지 않는다.
- 현재 자료는 개발자 명시 preview 전용이다. release 목록은 비어 있으며 최초 검수 대상 C005/C011/C017도 승인하지 않았다.
- 외부 사이트나 한컴타자의 문제·코드·UI·캐릭터·음원·이미지를 복사/수집하지 않았다. 오디오와 이미지 참조는 전부 null이다. 직접 작성이라는 사실로 권리 검토 완료 또는 무침해를 선언하지 않는다.

개정 3의 대응은 `phụ âm = 자음 / consonant`, `hình chữ = 글자 모양 / letter shape`, `nguyên âm = 모음 / vowel`, `âm tiết = 음절 / syllable`이다. VI 변형의 `explanations`와 `usageNote`만 바꾸고 KO/EN 변형 전체, VI 목표 문구·보기·키 안내, C005~020은 보존했다. 새로운 발음 음원이나 베트남어 전체 교육 과정을 추가하지 않았다. 이 풀이·번역도 자체 작성한 검수 전 초안이다. 과거 revision 2 기록을 해당 개념의 revision 3 성취로 자동 이전하지 않는다.

개정 3 검증: `npm test -- tests/content.test.ts`의 19개 테스트가 통과했다. 네 VI 목표의 대응 뜻·베트남어 입력 안내, KO/EN 학습 내용 유지, 개정별 정확한 scope, `draft`/`null` 유지, preview 20개·release 0개를 확인했다. 수정 전 로컬 원본과 JSON 필드를 대조해 허용한 풀이·사용 안내·개정·scope·교육/VI notes 이외의 변경이 없음을 확인했다. 이 검사는 구조와 표시 의미의 회귀 검사이며 원어민·교육 전문가 검수가 아니다.
