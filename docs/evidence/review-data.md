# 콘텐츠·저장 독립 검수

검수일: 2026-09-30 · 검수자: 별도 `review_data` 에이전트(OpenAI Codex). 정확한 런타임 모델 식별자는 이 에이전트에 제공되지 않아 특정 모델 간 교차 검수로 주장하지 않는다. 구현 담당 `build_data`와 분리되었으며 제품 파일은 수정하지 않았다.

상태: **대상 결함 RD-01~06 수정 확인 / 로컬 검수 PASS**. 최초 검사 실패 뒤 구현 담당이 수정했고 독립 재검증했다. 아래 실제 환경·전문가 검수는 계속 미완료이며 이 판정은 전체 MVP 수용이 아니다. 검수 범위는 [콘텐츠 검증기](../../src/content/validate.ts), [콘텐츠](../../content/core-draft.json), [저장 어댑터](../../src/storage/index.ts), 해당 테스트와 D001/D004/MH-011/MH-012 계약이다.

독립 fixture는 `.local/review-data/review.fixture.ts`에 저장했다. 전용 config만 이 파일을 실행하므로 일반 `npm test`에 추가되지 않는다. 실제 사용자 저장소를 수정하지 않고 메모리 StorageLike와 복제된 콘텐츠를 사용했다.

## 초안 편집 확인

- **SHOULD_FIX RD-05:** 오답 피드백 템플릿의 한국어 조사 결합이 잘못된 곳이 있다. 예: `content/core-draft.json:581`의 `이 문제는 "물"를 뜻해요.`. `책`, `학교` 등의 명사 뒤 조사·서술격도 전체 템플릿에서 점검해야 한다. 명사를 독립된 표시로 분리하는 문장 등으로 수정하면 조사 자동 선택을 과도하게 구현하지 않아도 된다.
- **SHOULD_FIX RD-06:** C001~C004의 EN/VI 변형도 KO 변형의 키 도움말을 그대로 사용한다. 예를 들어 `consonant`를 입력하는 EN 변형(C001, `core-draft.json:49`)에서 `한국어 두벌식 r` 안내가 나타난다. KO의 자모 키 안내와 현재 연습 언어의 입력 방법을 구분하고 실제 목표 단어를 입력할 수 있게 안내해야 한다. UI는 keyboardHint를 사용하므로 데이터 수정이 학습자에게 반영된다.
- 카페 보기의 음료·수량·온도는 목표 문장에 명시된 조건과 일치하는 구성이다. 눈으로 확인한 범위에서 정답 ID에 대응하는 기본 의미 모순은 찾지 못했다. 이를 자연스러움·교육 적합성·권리 승인으로 판단하지 않는다.
- 베트남어 `Tôi là học sinh.`의 연령·교육 단계 적합성, 요청 문구 `Cho tôi …, làm ơn.`의 상황·자연스러움, 한국어 생략 주어와 EN/VI 주어 표현은 계획된 전문가 검토 대상으로 남긴다. 이 검수에서 내용을 approved로 변경하지 않았다.

## 유지할 경계

기본 release가 현재 draft 콘텐츠를 제외하는 동작, NFC 목표 검증, 미등록 권리 ID/미승인 미디어 차단, 미래·손상 저장 보호, 원시 입력 extra-field 거부, 최근 기록 90일/200개 보존, first/retry 집계 분리의 기존 검사는 통과했다. 다중 탭 원자 병합·실제 브라우저 저장 차단·실제 키보드 조작 성공을 의미하지 않는다. 실제 지원 및 MVP 수용 상태는 [Harness 기록](../I004-harness-development.md)과 해당 티켓의 근거를 따른다.

## 수정 후 독립 재검증 · 2차

- **RD-01 해결:** scope의 개념·개정·영역을 정확한 토큰으로 비교한다. 재현 fixture를 현재 `revision`에서 파생하도록 고쳤다. revision 2에 `MH-C005@20` 승인은 차단되고 `MH-C005@2`의 정확한 영역은 통과한다. `en` 대신 `english`를 적은 범위는 차단된다. 원래 고정된 @10만 검사하면 개정 변경 때문에 결함이 사라진 것처럼 보일 수 있어 이 보완을 적용했다.
- **RD-02 해결:** 저장소 없는 메모리 모드의 학습 기록 삭제가 언어 설정을 보존하면서 기록을 지운다. 삭제 전 revision의 스냅샷은 거부한다. 실제 저장소의 쓰기·삭제 실패 처리 검사는 그대로 통과했다.
- **RD-03 해결:** retry가 복습 큐에 새 오답을 추가하거나 첫 시도 오류를 지우지 않는다. 집계·최근 이력에는 재시도 기록을 유지한다.
- **RD-04 해결:** recentAttempts의 이벤트가 속한 집계와 그룹·개념·개정·언어를 검사하고, 최신 이벤트의 전체 값도 대조한다. 복습 큐의 마지막 이벤트와 해당 개념 연결, 중복 큐도 검사한다.
- **RD-05 해결:** 의미 과제 16개 × 3언어 변형 × 오답 보기 2개 = **한국어 피드백 96개**를 확인했다. 모두 `선택한 보기: … . 이 문제의 뜻: … .` 형태로 보기·정답 레이블과 일치하며 부적절한 조사 자동 결합이 제거됐다.
- **RD-06 해결:** 자모 4개 × EN/VI 변형 = **8개 도움말 묶음**이 현재 연습 언어에 맞는 영어 입력 또는 베트남어 Telex/VNI 안내를 제공한다. 한국어 두벌식 키 안내는 KO 변형에 유지한다.
- 현재 **20개 개념 모두 revision 2**, 검수 5영역은 draft, 담당·승인일·근거 null, packVersion null이다. 오디오·이미지 null 유지와 60개 변형을 확인했다. 구조 검사와 편집 수정이 실제 언어·교육·권리 승인을 대신하지 않는다.

이 독립 검수 범위에서 미해결 MUST_FIX/SHOULD_FIX는 없다. 브라우저 저장 정책·다중 탭 실조작, 실제 베트남어/한국어 IME, 현지 언어·교육 전문가·권리 검수는 **SKIP/별도 수용 게이트**다. UI 전체 검사·빌드는 이 검수에서 중복 실행하지 않았으며 통합 Harness 기록을 따른다.
