# MH-012 · 오류 유형 복습·진도·이어하기

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

입력과 의미 중 어려웠던 부분을 골라 다시 연습한다.

## 선행 티켓과 착수 조건

## 구현 작업과 예상 변경 모듈

- 첫 결과로 오류 유형별 큐를 만들고 명시적 재시도 결과를 별도로 남긴다.
- 복습 진입 기본 해석 표시와 사용자 숨김/hintExposed 규칙을 구현한다.
- 같은 탭 확정값 재개·reload 미완료 재시작·콘텐츠 버전 변경을 연결한다.
- 예정 모듈/결과물: src/progress 복습 큐·진도 화면·이어하기 및 근거.

## 수용 기준

1. 입력 오답·의미 정답인 결과는 입력 복습 큐에만 들어간다.
2. 복습 준비 화면의 기본 설정은 해석 표시다. 문항을 렌더하기 전에 숨김 시작을 직접 고른 경우에만 처음부터 숨긴다. 이미 보인 문항에서 숨김을 눌러도 새 시도나 무힌트 기록을 만들지 않는다.
3. 의미 복습은 해석 없는 새 시도의 첫 정답으로 해결되며, 같은 복습 방문에서 해당 문항의 해석을 먼저 봤거나 첫 오답이면 남는다. 즉시 재시작으로 노출 이력을 지우지 않는다.
4. 새로고침은 미완료 문제를 빈 입력으로 재시작하며 이미 완료한 문제를 중복 집계하지 않는다.
5. 문항 revision 변경 시 이전 오류/성과를 현 버전 숙달로 승계하지 않는다.

## 검증 방법과 실제 환경
