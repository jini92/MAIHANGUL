# MH-018 · 20개 전체 콘텐츠·UI 문구·권리 수용

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

MVP 전체 문항과 메뉴·오류 문구가 검수된 상태로 제공되게 한다.

## 연결 요구사항·설계

R02, R03, R04, R16, R18 · [요구사항](../A001-PRD.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V02, V03, V04, V16, V18

## 포함·제외 범위

20개 개념 전 변형·UI 3언어 문구·라이선스/검수 근거. 법적 무침해 확약·상표 등록·음성 계약 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-004](MH-004.md), [MH-005](MH-005.md), [MH-015](MH-015.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- 최소3 검수 이후 나머지17 및 변경된 문항의 교육/VI/EN 검수를 완료한다.
- 메뉴·오류·설정·결과 UI 문구까지 번역 검토 범위를 확장한다.
- 팩 manifest의 revision·권리 장부·실제 파일·검수 대상 해시를 대조한다.
- 예정 모듈/결과물: 20개 검수 완료 팩 또는 미완료 사유 목록, UI 검수표·권리 근거.

## 수용 기준

1. 20개 모두 최신 revision의 ko/en/vi 변형과 풀이/보기/피드백 검수 근거가 연결된다.
2. 미해결 번역·높임말·보기 모호성·권리 보류가 있는 문항은 release 목록에 없다.
3. UI 3언어 누락/오역 검토를 완료하고 제품에 반영한 버전이 기록된다.
4. 도입한 음성/폰트/이미지가 있다면 개별 권리 근거를 갖추고, 없으면 없음으로 기록한다.

## 검증 방법과 실제 환경

교육·VI·EN 실제 검수와 권리 장부 대조, MH-003 검증기. 검수 의뢰/비용/외부 전달은 승인 범위 확인.

## 결과물

20개 검수 완료 팩 또는 미완료 사유 목록, UI 검수표·권리 근거. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.

## 우선순위·크기·상태
