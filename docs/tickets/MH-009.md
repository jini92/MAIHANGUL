# MH-009 · 한 문제 입력·채점·해석·결과 연결

기준일: 2026-09-30 · 구현 결과와 정식 수용 상태는 아래 실행 결과를 구분해 읽는다.

## 목적과 사용자 변화

검수된 한 문제를 처음부터 끝까지 연습할 수 있게 한다.

## 연결 요구사항·설계

R01, R02, R03, R06, R09, R17, R18 · [요구사항](../A001-PRD.md) · [D002](../D002-learning-game-ux.md) · [D003](../D003-input-scoring.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V01, V02, V03, V06, V09, V17, V18

## 포함·제외 범위

자모·자판 안내와 입력, 단어·생활문장 입력/피드백/3언어 해석/결과·재시도. 카페 연출·영속 진도 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-005](MH-005.md), [MH-006](MH-006.md), [MH-007](MH-007.md), [MH-008](MH-008.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- 최소 검수 팩과 실제 입력/채점 모듈을 화면에 연결한다.
- 처음 표시·틀림·정답·재시도·중단·빈 콘텐츠 상태를 만든다.
- ko/en/vi 연습 변형과 UI 전환의 상태 유지·포커스를 연결한다.
- 자모의 한글 키 위치·조합 안내와 en/vi 글자 이름/설명 변형을 구현한다. meaningTask=null은 의미 단계를 건너뛰고 결과에 해당 없음을 표시한다.
- 예정 모듈/결과물: 한 문제 전체 흐름과 화면별 검증 근거.

## 수용 기준

1. 검수된 문항을 열면 원문 아래 ko 풀이/en/vi 해석이 모두 보이며 일반 연습에서는 숨길 수 없다.
2. 틀린 입력 제출 후 정확도와 비교 피드백을 보여주고 명시 재시도 또는 실패 기록 후 계속을 제공한다.
3. UI 언어를 전환해도 현재 문항·입력·첫 결과가 유지된다.
4. draft만 있는 팩을 release 모드로 열면 연습을 시작하지 않고 빈 목록 안내를 보인다.
5. 자모 개발 fixture에서 ko 자판 안내와 조합 입력, en/vi 설명 문구 입력을 각각 완료하면 입력 결과만 표시하고 의미 점수는 null이다. 이 초안 기능 검사는 콘텐츠 검수 통과가 아니며 실제 자모 콘텐츠 제공은 MH-018/019의 검수 뒤에만 허용한다.

## 검증 방법과 실제 환경

3개 검수 개념과 3언어 입력 × 3개 UI, Chrome/Edge 기능 통합. 초안 fixture로 개발 가능하지만 수용은 MH-005 이후.

## 결과물

한 문제 전체 흐름과 화면별 검증 근거. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
