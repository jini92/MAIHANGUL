현재 저장소 라벨은 GitHub 기본 라벨과 accessibility이며, 계획한 priority:*/area:*/phase:* 라벨은 아직 없다. 티켓의 세 라벨을 정확한 이름으로 준비했다. 발행 승인 범위에는 필요한 라벨 생성과 티켓 간 의존 URL 반영을 포함해 요청한다. 기존 라벨은 삭제·개명하지 않는다.
