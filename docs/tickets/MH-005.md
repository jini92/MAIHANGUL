# MH-005 · 단어·생활문장·카페 3개 기준 문항 검수

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

첫 작동 흐름을 부정확한 번역이나 정답으로 수용하지 않게 한다.

## 연결 요구사항·설계

R02, R03, R04, R16 · [요구사항](../A001-PRD.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V02, V03, V04, V16

## 포함·제외 범위

C005 물·C011 안녕하세요·C017 물을 주세요의 세 언어 변형·풀이·보기·권리 근거 검수. 나머지 17개 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-004](MH-004.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- 한국어 교육, 베트남어, 영어 검수표를 검수자별로 준비한다.
- 수정 요청을 콘텐츠 revision에 반영하고 바뀐 필드 재검수를 기록한다.
- 승인된 정확한 revision 3개만 수용용 최소 팩으로 구분한다.
- 예정 모듈/결과물: 최소 3개 검수 팩과 검수 기록/수정 이력.

## 수용 기준

1. 3개 개념의 모든 변형/해석/보기/피드백에 검수자·일자·판정·대상 revision 근거가 있다.
2. 번역·높임말·정답 모호성 지적이 남으면 해당 revision은 수용 팩에 없다.
3. 권리 근거와 출처 장부 ID가 맞고, 오디오가 없으면 null로 유지한다.

## 검증 방법과 실제 환경

한국어 교육 검토자·베트남어 원어민 수준 검토자·영어 검토자의 실제 검토 근거. 구조 검사만으로 완료 불가.

## 결과물

최소 3개 검수 팩과 검수 기록/수정 이력. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
