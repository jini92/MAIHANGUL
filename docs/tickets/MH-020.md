# MH-020 · 소규모 사용성·의미 회상 파일럿

## 목적과 사용자 변화

대상 가정과 혼자 학습할 수 있는지 확인하고 다음 개선점을 찾는다.

## 연결 요구사항·설계

R01, R09, R19 · [요구사항](../A001-PRD.md) · [T001](../T001-validation-plan.md) · [A001](../A001-PRD.md) · [검증 계획](../T001-validation-plan.md): V01, V09, V19

## 포함·제외 범위

승인 후 소수 성인 베트남어권 PC 초급자의 과제·지연 의미 회상·재사용 탐색. 대규모 학습효과 실험·이번 모집/연락 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-019](MH-019.md).
- 착수 조건: 후속 평가로 일정 미편성. 선행 수용과 모집·연락 명시 승인, 실제 진행자/환경이 필요하다.

## 구현 작업과 예상 변경 모듈

- T001 프로토콜의 인원·동의·자료 최소화·측정 간격을 실행 전에 고정한다.
- 타자/의미·힌트 유무·도움 요청·완료 시간·재사용을 각각 기록한다.
- 소수 표본 한계와 사전 지식·문항 반복 영향을 포함하여 개선 티켓을 작성한다.
- 예정 모듈/결과물: 익명화된 관찰 요약·가정 수정·다음 개선 티켓.

## 수용 기준

1. 모집/연락 전에 사용자 승인·진행자·동의/보존 계획이 기록되어야 실행한다.
2. 참가자별 타자 변화와 의미 첫 선택/지연 회상 결과가 별도 표이고 힌트 노출을 구분한다.
3. 미참여/중도중단/다른날 재사용 미관찰을 성공값으로 대체하지 않는다.
4. 소수 관찰을 교육효과의 인과적 증거로 결론 내리지 않는다.

## 검증 방법과 실제 환경

T001의 5명 제안 프로토콜과 실제 PC 세션. 승인 전에는 준비만 가능.

## 결과물

익명화된 관찰 요약·가정 수정·다음 개선 티켓. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
