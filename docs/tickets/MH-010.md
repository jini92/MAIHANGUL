# MH-010 · 시간제한 없는 독자 카페 의미 게임

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

입력한 문장의 뜻에 맞는 사물을 골라 의미 이해를 연습한다.

## 연결 요구사항·설계

R01, R04, R09, R10 · [요구사항](../A001-PRD.md) · [D002](../D002-learning-game-ux.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V01, V04, V09, V10

## 포함·제외 범위

자체 텍스트 카드 3보기·정답1·피드백·다음 문제. 타사 자산·실시간 대전·타임어택 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-009](MH-009.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- 입력 결과→의미 선택→분리 결과 상태를 만든다.
- 보기 id와 locale 라벨을 분리하고 선택/제출 잠금을 적용한다.
- 키보드 라디오 이동·확인·재시도 포커스를 연결한다.
- 예정 모듈/결과물: src/game 카페 상태와 화면/기능 근거.

## 수용 기준

1. ‘물을 주세요.’ 입력 후 물/다른 사물의 3보기를 표시하고 물 선택을 의미 정답으로 기록한다.
2. 입력 오답/의미 정답을 독립 결과로 보여주며 하나의 합산 점수로 바꾸지 않는다.
3. 선택 확인을 반복해도 의미 첫 결과가 1회만 기록된다.
4. 30초 이상 기다려도 문제 탈락·자동 진행·시간 압박 알림이 없다.

## 검증 방법과 실제 환경

검수된 cafe 문항·Chrome/Edge·키보드와 포인터, 정답·오답·재시도·중단 경로.

## 결과물

src/game 카페 상태와 화면/기능 근거. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
