## 상태와 크기

- Ready: 지금 독립적으로 착수할 수 있는 작업. 실행/합격을 의미하지 않는다.
- Blocked: 선행 수용 또는 명시한 외부 검수/환경 확보 전에는 해당 결과를 수용할 수 없다.
- Backlog: 후속 범위로 일정 미편성.
- Done: 해당 티켓의 로컬 수용 기준과 선행 근거가 충족됨. 배포·외부 검수 완료를 뜻하지 않는다.
- Blocked인 티켓에도 구현과 자동 검사 완료 부분이 있다. 상태는 남은 수용 조건을 나타내며 언어 기능 미지원 표시가 아니다.
- P0: 선행 위험·핵심 수용 차단 사항, P1: MVP 기능·품질, P2: MVP 이후 탐색.
- S: 집중 작업 약 0.5~2 개발일, M: 약 2~4 개발일의 거친 추정. 실기 협조·번역 검수·승인 대기는 별도다.
- ID는 재사용하지 않는다. 후속 완료 때 근거를 남긴 뒤 상태 체계/완료 기록을 확장하며, 현재 문서 작성만으로 티켓을 Done으로 만들지 않는다.
