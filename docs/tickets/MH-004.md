## 구현 작업과 예상 변경 모듈

- 4자모·6단어·6생활문장·4카페 개념별로 ko/en/vi 변형을 자체 작성한다.
- 언어별 의미 정보와 3보기/정답 1개(의미 과제 해당 시)를 작성한다.
- 저작/번역 도구·날짜·수정 이력과 권리 장부 참조를 남긴다.
- 예정 모듈/결과물: 20개 draft 콘텐츠와 작성·출처 기록. 패키지 수량·검수 상태 보고.

## 수용 기준

1. 20개 고유 ID와 각 3개 연습 변형을 검사하면 구조 누락이 없다.
2. 새 문항의 교육·VI·EN·권리 상태는 draft이며 검수 착수 후 inReview로 바꾼다. approved 근거 전에는 release 목록이 비어 있다.
3. 자모 en/vi 변형은 짧은 이름/설명 연습이며 한국어 발음의 임의 로마자 등치가 없다.
4. 카페 정답은 사물 의미로 식별되며 보기별 라벨·설명은 3언어로 제공된다.
