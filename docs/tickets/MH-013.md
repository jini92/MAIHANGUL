# MH-013 · 오디오 부재·재생·실패 흐름

기준일: 2026-09-30 · 구현 결과와 정식 수용 상태는 아래 실행 결과를 구분해 읽는다.

## 목적과 사용자 변화

음성이 없거나 재생에 실패해도 학습을 계속한다.

## 연결 요구사항·설계

R04, R14 · [요구사항](../A001-PRD.md) · [D001](../D001-architecture-overview.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V04, V14

## 포함·제외 범위

오디오 어댑터·상태 안내·수동 재시도. 음성 제작·외부 TTS·라이선스 구매 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-003](MH-003.md), [MH-006](MH-006.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- audio=null을 기본 지원하고 승인되지 않은 자산 재생을 차단한다.
- 사용자 활성화로만 재생·중지, 오류·새 문제·중단 처리를 만든다.
- 자체 권한 있는 짧은 테스트 fixture를 후속 구현에서 준비해 실패 주입을 검사한다.
- 예정 모듈/결과물: src/audio와 UI 상태·실패 근거.

## 수용 기준

1. audio=null 문항은 이용 불가 안내와 정상 텍스트 연습을 제공한다.
2. 파일 없음/재생 거부 시 3언어 안내·수동 재시도가 나타나며 점수는 바뀌지 않는다.
3. 문항 전환/중단 때 이전 음성 재생이 멈추며 자동 재생하지 않는다.
4. 권리 상태가 draft/inReview인 자산은 경로가 있어도 학습용 재생 대상에 포함되지 않는다.

## 검증 방법과 실제 환경

브라우저 실제 media 재생·실패 fixture; 오디오 없는 상태와 권리 gate 검사.

## 결과물

src/audio와 UI 상태·실패 근거. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.

## 우선순위·크기·상태

P1 · S · Blocked. 크기는 [INDEX](INDEX.md)의 상대 추정이며 외부 대기 시간은 포함하지 않는다.

## 미확정 사항·외부 의존

실제품 음성 도입/검수/비용 미정. 음성 자산 없이도 실패/부재 기능은 수용 가능.

## 실행 결과

음성 부재 안내·권리 상태·재생 실패 처리를 구현하고 모의 오디오 검사를 수행했다. 실제 승인 음원은 없으며 실제 브라우저 재생 검증 대기다.

근거: [하네스 실행·통합 검증](../I004-harness-development.md)

로컬 구현/수용 상태이며 GitHub 이슈의 원격 완료 여부와 구분한다. 실제 환경·외부 검수 조건은 자동 검사로 면제하지 않는다.
