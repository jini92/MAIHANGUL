# MH-014 · 키보드·확대·스크린리더 접근성 검증과 수정

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

마우스나 소리 없이도 전체 흐름을 이해하고 조작하게 한다.

## 연결 요구사항·설계

R13, R17 · [요구사항](../A001-PRD.md) · [D002](../D002-learning-game-ux.md) · [검증 계획](../T001-validation-plan.md): V13, V17

## 포함·제외 범위

5개 화면 접근성 결함 수정와 실제 보조기술 검사. 모바일 전용 레이아웃/인증서 수준 준수 선언 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-010](MH-010.md), [MH-012](MH-012.md), [MH-013](MH-013.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- Tab/Shift+Tab/라디오/Enter·Space·대화상자 포커스 복귀를 점검한다.
- 200% 확대·대비·보이는 포커스·색상 외 피드백을 검사한다.
- Windows 스크린리더와 각 언어 lang, 오류/live 알림을 확인한다.
- 예정 모듈/결과물: 접근성 수정·화면/절차별 검사 기록.

## 수용 기준

1. 키보드만으로 시작→입력→의미 선택→결과→복습→삭제 확인 취소까지 완료한다.
2. 조합 중 문자마다 오류/정답 알림을 읽지 않으며 제출 후 결과는 한 번 명확히 전달한다.
3. 200% 확대에서 필수 조작과 문구가 가려지지 않고 포커스가 보인다.
4. 중단 대화상자를 취소하면 원래 조작 위치로 복귀하며 포커스 함정이 없다.

## 검증 방법과 실제 환경

Chrome/Edge, 실제 Windows Narrator 또는 확인된 NVDA, 키보드, 대비 측정. 자동 도구 통과만으로 완료 불가.

## 결과물

접근성 수정·화면/절차별 검사 기록. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
