# MH-016 · 통합 화면 실제 Windows IME 수용 검증

기준일: 2026-09-30 · 구현 결과와 정식 수용 상태는 아래 실행 결과를 구분해 읽는다.

## 목적과 사용자 변화

단독 실험과 실제 게임 화면 사이의 IME 회귀를 찾아낸다.

## 연결 요구사항·설계

R07, R08, R09, R17 · [요구사항](../A001-PRD.md) · [D003](../D003-input-scoring.md) · [검증 계획](../T001-validation-plan.md): V07, V08, V09, V17

## 포함·제외 범위

Windows Chrome/Edge의 한국어 두벌식·Telex·VNI·영문 실제 입력 8환경. 지원하지 않은 OS/모바일 선언 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-007](MH-007.md), [MH-009](MH-009.md), [MH-010](MH-010.md), [MH-012](MH-012.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- T001 환경표에 정확한 버전·물리 키보드·입력 방법·콘텐츠 revision을 남긴다.
- 조합·취소·Enter·삭제·Tab/클릭·전환·붙여넣기를 통합 화면에서 실행한다.
- 실패 수정 후 해당 경계를 재검증하고 로그/화면 근거를 연결한다.
- 예정 모듈/결과물: docs/evidence/MH-016-real-ime.md와 환경별 실행 기록·수정 내역.

## 수용 기준

1. 한국어 조합 중 오답/제출은 0회이고 새 버튼 활성화는 정확히 1회 제출한다.
2. Telex/VNI로 성조를 넣고 수정하면 최종 문자 그대로 비교되고 성조 없는 답은 틀린다.
3. 중단/문제 전환 이후 늦은 이벤트로 현재 값·점수가 바뀌지 않는다.
4. 8환경 필수 절차의 실제 근거가 모두 있어야 완료다. 합성 이벤트·fill·스크린샷만으로 실기 완료 처리하지 않는다.

## 검증 방법과 실제 환경

실제 Windows·Chrome/Edge·한국어 IME/Telex/VNI/영문·현지 조작자. 자동 브라우저 테스트와 별도 실기 결과.

## 결과물

docs/evidence/MH-016-real-ime.md와 환경별 실행 기록·수정 내역. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.

## 우선순위·크기·상태

P0 · M · Blocked. 크기는 [INDEX](INDEX.md)의 상대 추정이며 외부 대기 시간은 포함하지 않는다.

## 실행 결과

실제 Windows IME 통합 검증은 미실행이다. E01~E08 환경별 관찰이 필요하며 합성 검사를 실기 수용으로 바꾸지 않는다.

근거: [하네스 실행·통합 검증](../I004-harness-development.md) · [개별 근거](../evidence/MH-001-ime.md)
