# MH-015 · 3개 UI·연습 언어 조합 통합 검증

기준일: 2026-09-30 · 상태는 **착수 준비 상태**이며 이번 작업에서 구현·테스트를 실행한 것이 아니다.

## 목적과 사용자 변화

영어·베트남어 지원이 메뉴 일부에 그치지 않게 확인한다.

## 연결 요구사항·설계

R02, R03, R06, R18 · [요구사항](../A001-PRD.md) · [D002](../D002-learning-game-ux.md) · [D004](../D004-content-data-rights.md) · [검증 계획](../T001-validation-plan.md): V02, V03, V06, V18

## 포함·제외 범위

UI 3 × 연습 3 조합의 메뉴/해석/오류/결과와 누락 대응. 전체 독립 과정 제외.

## 선행 티켓과 착수 조건

- 선행: [MH-009](MH-009.md), [MH-010](MH-010.md), [MH-012](MH-012.md), [MH-013](MH-013.md).
- 착수 조건: 선행 티켓의 수용 근거가 모두 연결되어야 Ready로 옮긴다. 아래 외부 의존도 별도로 충족한다.

## 구현 작업과 예상 변경 모듈

- 9개 조합에 동일한 흐름·빈 목록·저장/음성 오류·재개 검사를 적용한다.
- 언어 전환 시 입력·보기 ID·점수 보존과 화면 lang을 검사한다.
- 누락 번역 fixture가 fallback을 알리고 release 검사에 실패하는지 확인한다.
- 예정 모듈/결과물: 9조합 × 두 브라우저 결과표·결함 수정.

## 수용 기준

1. 9개 조합에서 원문과 ko/en/vi 해석이 서로 덮어쓰지 않고 문제 아래에 표시된다.
2. UI 전환 후 의미 보기 라벨만 바뀌며 선택 ID·첫 결과는 같다.
3. 일반 연습은 해석 숨김이 없고 복습은 명시 선택으로만 숨긴다.
4. 문항 번역 누락은 해당 문항 제외·빈 목록 안내, UI 키 누락은 명시 fallback 및 수용 실패다.

## 검증 방법과 실제 환경

Chrome/Edge 9조합 수동/브라우저 검사, 최소 검수 팩과 누락 fixture. 언어 자연스러움은 MH-018 검수 근거 병행.

## 결과물

9조합 × 두 브라우저 결과표·결함 수정. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
