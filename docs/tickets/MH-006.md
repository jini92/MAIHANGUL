# MH-006 · 로컬 앱 기반과 3언어 UI 설정

기준일: 2026-09-30 · 구현 결과와 정식 수용 상태는 아래 실행 결과를 구분해 읽는다.

## 목적과 사용자 변화

계정 없이 시작하고 UI 언어·연습 언어를 따로 고르는 기반을 만든다.

## 연결 요구사항·설계

R02, R06, R13, R15, R19 · [요구사항](../A001-PRD.md) · [D001](../D001-architecture-overview.md) · [D002](../D002-learning-game-ux.md) · [검증 계획](../T001-validation-plan.md): V02, V06, V13, V15, V19

## 포함·제외 범위

React/TypeScript/Vite 로컬 실행, 3언어 키, 시작/설정 화면. 채점·게임·서버·배포 제외.

## 선행 티켓과 착수 조건

- 선행: 없음.
- 착수 조건: 문서 계약이 준비되어 독립 착수 가능하다. 환경 확인·최소 도구 준비를 포함한다. 실기나 외부 검수의 완료 조건은 생략할 수 없다.

## 구현 작업과 예상 변경 모듈

- Node·패키지 버전 호환을 확인하고 최소 의존성/lockfile을 만든다.
- uiLocale/practiceLanguage와 복습 해석 상태를 분리한다.
- 시작·빈 목록·오류·설정·로컬 저장 안내의 3언어 문구와 기본 HTML 접근성을 만든다.
- 예정 모듈/결과물: 최소 앱 기반, 3언어 UI 키·시작 화면, 실행 방법 문서.

## 수용 기준

1. 로컬 시작 화면에서 ko/en/vi UI를 바꾸면 메뉴·오류·도움말 문구와 lang이 함께 바뀐다.
2. UI 언어를 바꾸어도 선택한 연습 언어는 유지된다.
3. 첫 실행은 로그인/외부 API/분석 전송 없이 시작하며 기본 해석 표시는 켜져 있다.
4. 자모→단어→문장→카페 순서를 보여주되 단계는 잠기지 않는다.

## 검증 방법과 실제 환경

로컬 빌드·타입 검사, Chrome/Edge에서 3언어 시작·설정·키보드 확인. 후속 개발 승인으로 패키지를 설치했다. 실제 실행 결과와 환경은 I004를 따른다.

## 결과물

최소 앱 기반, 3언어 UI 키·시작 화면, 실행 방법 문서. 완료 시 실제 실행 명령/절차·버전·예상/실제·근거 링크·잔여 문제를 첨부한다.
