# I005 · 자판 중심 FE 디자인과 도구 연동

기준일: 2026-09-30 · 상태: 자판 FE 구현·검수, Stitch 인증·시안 생성, Blender 설치·실제 씬 연결 완료

## 계획

- 목표: 키보드 자판·현재 안내 키·누른 키를 직관적으로 보여주는 로컬 FE와 Stitch/Blender의 가능한 실제 연결.
- 기준: master `01288d88d412a81a41bb76650901df58cbfc6253`와 이전 턴의 미커밋 구현. 변경 전 파일을 `.local/keyboard-design-before/`에 보존하며 기존 작업을 대체하지 않는다.
- 적용: karpathy-guidelines, frontend-design, Harness default. 외부 생성물·타사 화면 복사 없이 자체 디자인.
- 가정: PC QWERTY/한국어 두벌식 우선. 베트남어는 OS 입력기와 QWERTY 기반 안내를 사용한다. 앱 내 가상 입력기 도입은 제외한다.
- 선택: DOM/CSS 자판은 글자·강조·접근성을 직접 제어하므로 3D 이미지보다 학습 기능에 적합하다. Blender 연결은 디자인 도구로 따로 검증한다.
- 성공 기준: 키 배열/목표 안내/물리 키 눌림·해제, 조합 중 기존 채점 보호, 세 언어 표시, 기존 회귀 검사, 실제 브라우저 가독성·반응형 확인, 별도 검수의 지적 수정. 외부 MCP는 설치·등록·인증·실호출을 구분한다.
- 승인 범위: 사용자의 FE 업데이트 및 Stitch/Blender 추가 연결. 외부 게시·commit/push·배포·유료 생성·기존 씬 삭제는 포함하지 않는다.

## 정본과 역할

- [디자인 토큰과 동작 계약](../design.md)
- 구현 담당: 자판/React/CSS/3언어 안내/행동 검사.
- 도구 연동 담당: Stitch 공식 MCP/스킬, Blender 커뮤니티 MCP·앱·애드온, 두 에이전트 설정과 실제 연결 근거.
- 통합 담당: 한컴타자 공개 기능 관찰, 브라우저 시각 검사, 변경 범위·문서 정합성.
- 독립 검수: 구현에 참여하지 않은 에이전트의 입력 보호·매핑·접근성·계약 검토.

## 관찰과 실행 경계

[한컴타자](https://www.hancomtaja.com/ko)에서 자리 연습 링크를 통해 열린 `tt.hancomtaja.com`의 공개 온보딩 화면을 관찰했다. 목표 글자·자판·안내의 관계를 참고했으며 자산을 복제하거나 실제 학습 효과를 검증한 것이 아니다.

이번 턴은 브라우저 연결이 정상이다. 기존 사용자 탭의 연습·로컬 기록을 보존하기 위해 브라우저 테스트는 별도 포트 5174의 로컬 origin에서 수행한다. 실제 물리 OS IME 검증과 브라우저 자동 입력은 구분한다.

## 결과

### 구현

- `src/keyboard/layout.ts`: QWERTY 5행·두벌식 자모·Shift·F/J 표식과 단일 자모/음절의 정적 키 순서·손가락 안내.
- `src/components/KeyboardGuide.tsx`와 CSS: 읽기용 자판, 목표 위치의 밝은 테두리와 누른 키의 진한 채움. 작은 화면에서는 자판 영역 하나만 Tab으로 접근하여 좌우 방향키·Home·End로 탐색한다.
- `src/keyboard/usePressedKeys.ts`: 입력란의 `event.code`를 시각 표시에만 사용하고 해제·포커스 이탈·문항/상태 전환 때 비운다.
- 연습 목표·해석·입력·자판을 한 흐름으로 배치하고 홈에도 자판 미리보기를 넣었다. 800px 이하 높이의 PC에서 세로 여백을 줄였다. KO/EN/VI 문구와 Telex/VNI 입력 안내를 추가했다.
- 기존 input/scoring/storage의 계약을 바꾸지 않았다. 사용자 포트 5173의 학습 기록은 테스트용으로 초기화하지 않았다.

첫 시각 검사에서는 자판의 아래 두 행이 화면 밖으로 밀렸다. PC의 빈 상태 영역·헤더·행 간격을 줄여 다시 확인했다. 좁은 폭의 IAB에서는 포커스만으로 방향키 스크롤이 발생하지 않아, 자판 영역에 한정된 명시적 스크롤 동작을 추가하고 64px/끝 이동을 확인했다.

위 입력 검사는 브라우저 자동 입력 및 합성 DOM 검사다. 실제 Windows 한글 IME, Vietnamese Telex/VNI 키 입력, 화면 읽기 도구, 원어민 번역·교육 검수, 학습 효과를 합격 처리하지 않는다. benchmark는 미측정 상태를 유지한다.

- 인증·설치·실제 MCP 호출·재시작 방법은 [도구 연동 기록](evidence/design-integrations.md)을 따른다.
- [연동 설정 독립 검수](evidence/review-design-integrations.md): 새 MCP 두 개의 양쪽 설정·스킬 사본·자격증명 기록 경계, Blender ZIP 해시·실행 파일 서명·프로세스 경로·localhost 포트 소유자를 독립 확인했다. 저장된 씬 응답과 실행 기록도 대조했으며 최종 P1/P2 지적은 없다.

Stitch는 인증된 읽기와 시안 생성, Blender는 설치한 5.2.1 LTS의 유효한 Blender Foundation 서명과 실제 `get_scene_info` 응답을 확인했다. Blender 공식 서버의 HTTP 403은 공식 배포 파일을 제공하는 미러에서 재개 다운로드하고 최종 SHA256을 대조하여 해결했다. 새 검증 씬은 객체 0개·기존 파일 미로드 상태이며, 사용자 설정을 저장하지 않았다. 연결용 Blender 프로세스는 숨김 상태로 유지한다. Claude·Codex 등록 및 새 클라이언트의 로딩 조건은 연동 기록을 따른다.

Stitch는 비공개 프로젝트에서 비교용 시안 한 개를 생성했다. 제품은 자체 React/CSS 구현이며 생성 시안의 학습 해설·폰트·키 분류를 검수 없이 도입하지 않는다. 최종 제품의 녹색 윤곽/채움 토큰은 [design.md](../design.md)가 정본이다. 이번 변경은 로컬 master에 보존했으며 추가 commit/push/배포를 하지 않았다.
