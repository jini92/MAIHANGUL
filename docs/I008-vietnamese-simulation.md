# I008 · 베트남어 입력 방법 시뮬레이션

기준일: 2026-09-30 · 상태: 시뮬레이션·베트남어 과정 표시 로컬 검증 완료. 승인된 Pages 배포 진행 중.

## Plan

- **목표:** 베트남어 목표 문구를 입력하는 키 순서와 글자 변화를 연습 전에 볼 수 있게 한다. 현재 베트남어 문항에서 Telex/VNI를 선택하고 자동 재생·한 키 이동·처음부터 보기를 제공한다.
- **이유:** 자판 위치만으로는 모음 부호와 성조를 만드는 순서를 알기 어렵다는 사용자 피드백.
- **가정:** 현재 20개 베트남어 목표 문구의 안내부터 제공한다. 시연 방식 선택은 실제 PC 입력기 설정과 독립적이다. 지원하지 않는 새 문구에는 안내 불가를 표시한다.
- **선택:** 검토한 단어의 키 순서를 만드는 순수 함수와 기존 DOM 자판을 재사용한다. 학습용 화면은 입력기가 없어도 볼 수 있다. 실제 입력값·composition 이벤트를 합성하지 않는다.
- **대안:** 정적인 변환 표만으로는 여러 키가 합쳐지는 과정을 보기 어렵다. 범용 Telex/VNI 편집기를 앱에 내장하면 취소·삭제·외래어 처리까지 새 입력 엔진의 책임이 되므로 이번 기능에 필요하지 않다.
- **범위:** R03 다국어 설정, R08 베트남어 입력, R09 분리 지표를 보완한다. OS 입력기 설치·실기 수용·독립 베트남어 교육과정은 기존 검증 경계를 따른다.
- **크기 / preset:** 중간 / Harness `default`. 순수 계획 모듈과 FE를 분담하고 별도 에이전트가 검수한다.
- **시작 상태:** `master`, baseCommit `ba058cae08cbbf23997ad5223222d2bbf60956f6`. 시작 시 staged·unstaged·untracked 변경 없음.

### 관찰 가능한 완료 기준

1. 현재 베트남어 20개 목표 문구에서 두 방식의 마지막 프레임이 원문 NFC와 일치한다. 성조를 생략하지 않고 대문자는 Shift, 공백·구두점은 해당 키로 안내한다.
2. 예: `chào`는 Telex `c h a o f`, VNI `c h a o 2` 순서다. `chao` 다음에 성조 키를 누르면 `chào`가 표시된다.
3. 재생·일시정지·이전/다음 키·처음부터·방식 변경을 조작할 수 있다. 방식·문항 변경, 닫기, 창 이탈 때 예약 재생이 남지 않는다.
4. 시연은 입력란의 내용을 바꾸거나 채점·진도 기록을 만들지 않는다. 조합·확정 정리 중에는 열기 요청을 실행하지 않는다. 닫으면 직접 입력을 이어갈 수 있다.
5. 시연을 연 문제는 도움 사용으로 표시하고 속도 비교에서 제외한다. 시연의 키 수·재생 시간을 타자 성과로 사용하지 않는다.
6. 한국어·영어·베트남어 UI, 키보드 조작, 좁은 화면에서 안내와 자판을 확인한다.

## 입력 순서 근거와 한계

[UniKey 공식 사용자 설명서](https://www.unikey.org/support/ukmanual.html)의 입력 방법을 참고한다. 기본 글자 뒤에 모양 키를 넣고 성조는 단어 끝에 넣는 한 가지 경로를 안내한다. 설명서의 `tieengs Vieetj`, `dduwowngf` 및 VNI 대응 예시를 순서 검사에 사용한다. 설명서 원문이나 외부 코드를 제품에 복제하지 않는다.

시뮬레이션의 중간 글자는 이해를 돕는 구성 예시다. 실제 입력기의 설정·버전·맞춤법 처리에 따라 중간 표시나 허용되는 다른 키 순서는 달라질 수 있다. 실제 Windows 입력기로 키를 눌러 생성·수정·삭제한 검증과는 구분한다. MH-002/MH-016 실기 수용 상태는 이 기능으로 완료되지 않는다.

동작 정본: [D002 UX](D002-learning-game-ux.md#13-베트남어-입력-미리보기), [D003 채점 경계](D003-input-scoring.md#8-베트남어-입력-시뮬레이션). 화면 토큰은 [디자인 가이드](../design.md)를 따른다.

## 최초 시뮬레이션 로컬 실행 결과

- [순수 계획 함수](../src/keyboard/vietnameseSimulation.ts)는 현재 20개 목표에 쓰이는 31개 단어와 공식 예시를 지원한다. 문구·성조·대소문자·공백·구두점을 보존하고 미지원 입력은 부분 시연 없이 거절한다.
- [시연 컴포넌트](../src/components/VietnameseSimulator.tsx)와 [연습 화면](../src/components/PracticeSession.tsx)에 연결했다. 시연 방식은 독립 설정이며 실제 입력·채점·저장 모듈이나 콘텐츠 원문은 변경하지 않았다. 시연에 사용한 도움 기록은 기존 `assisted` 필드로 전달한다.
- 모듈 담당 `design_integrations`, FE 담당 `keyboard_ui`, 독립 검수 `keyboard_review`와 통합 담당이 작업했다. [독립 검수](evidence/review-vietnamese-simulator.md): 미해결 P1/P2 없음.
- **자동 검사 PASS:** `npm test` — 11파일·239개 통과. 이 중 입력 순서 104개와 UI·통합 13개를 추가했다. 조합/정리 중 열기 차단은 합성 이벤트 검사다.
- **빌드 PASS:** `npm run build:pages` — TypeScript 검사와 `/MAIHANGUL/` demo 빌드 성공. `git diff --check` 통과.
- **실제 브라우저 PASS:** IAB의 별도 `127.0.0.1:5174` 개발 서버에서 `Xin chào.`를 시연했다. Telex 9/10단계는 KeyF, VNI 9/10단계는 Digit2와 `Xin chào`를 표시했다. 대문자 첫 단계는 ShiftLeft+KeyX였다. 기존 직접 입력 `Xin`은 시연·닫기·방법 전환 동안 유지됐다.
- 재생을 시작하면 900ms 간격으로 진행하고 일시정지하면 프레임이 유지됐다. UI 언어를 KO→EN→VI로 바꿔도 시연 방식·진행 수·직접 입력값이 유지됐다. 시연을 닫으면 입력란으로 포커스가 돌아갔다. 콘솔 오류·경고는 0건이었다.
- **실제 화면에서 발견한 결함 수정:** 초기화·처음/끝 단계 이동 시 버튼이 비활성화되며 포커스를 잃어 연습 전체가 중단되는 문제를 고쳤다. 상태 변경 전에 재생 버튼으로 포커스를 옮긴다. 수정 후 초기화, 이전 1→0, 다음 9→10을 마우스·Enter로 재검증했다. 실제 창 이탈 보호는 유지했다.
- **좁은 폭 PASS:** 390×844에서 그리드의 자동 최소 폭 때문에 페이지가 656px로 늘어나는 문제를 발견했다. 좁은 화면의 열을 `minmax(0, 1fr)`로 바꾸고 시연 영역에 `min-width:0`을 지정했다. 재검증한 페이지 폭은 375px, 시연 패널 293px였다. 자판은 272px 영역 안에서 594px 콘텐츠만 가로 스크롤되고 End 키로 scrollLeft 322까지 이동했다. 화면 크기 임시 설정은 복원했다.
- 화면 근거: [VNI 성조 시연과 반투명 자판](evidence/screenshots/vietnamese-simulator-vni.png). 사용자 작업 중인 5173 탭과 기록은 조작하지 않았다.
- **미실행:** 실제 Windows Telex/VNI 설치·키 입력·편집, 전문가 번역·교육 검수, 학습 효과 검증. 이번 기능의 commit·push·배포는 실행하지 않았다. 기존 공개 체험 버전은 [I007](I007-github-pages.md) 상태다.

## 후속: 베트남어 학습 과정 표시

사용자는 시뮬레이션의 위치를 넘어 베트남어 학습 과정 자체가 보이지 않는다고 설명했다. 실제 5173 홈에서 UI 언어는 한국어, 연습 언어는 베트남어였지만 제목·한국어 학습 설명·“자모부터 시작” 버튼·R/ㄱ 안내가 그대로였다. 입력 대상만 바뀌는 기존 구현으로는 선택한 학습 과정을 홈에서 식별하기 어려웠다.

### 범위와 확인 기준

- 홈 제목·시작 버튼·단계 설명·실제 문구 예시·연습 화면의 단계 표시를 연습 언어에 맞춘다. UI 언어와 연습 언어는 계속 독립 설정이다.
- 현재 20개 문항을 쓰는 베트남어 입문 연습을 명시한다. 첫 단계는 글자 이름·입력, 뒤 단계는 단어·생활 문장·카페 주문이다. 새로운 전체 베트남어 교육과정을 제작했다고 표시하지 않는다.
- 일반 시작은 직접 입력, 별도 Telex/VNI 미리보기는 시연이 열린 실제 베트남어 문항으로 들어간다. 도움 사용 기록과 실제 입력 분리는 기존 계약을 유지한다.
- 첫 네 개 베트남어 변형에 남아 있던 한글 자모 설명은 해당 베트남어 단어의 뜻으로 바로잡는다. 개정·검수 경계는 [원고 이력](evidence/MH-004-content.md)을 따른다. 교육·번역 검수 상태는 초안으로 유지한다.
- 성공 기준: VI 선택 시 베트남어 홈·문구가 보이고 실제 VI 문항에 진입한다. KO 선택 시 기존 한국어 흐름을 보존한다. 세 UI 언어, 바로 시연 진입, 언어 변경 후 도움 플래그, 회귀 검사와 공개 화면을 확인한다.
- 시작 Git 기준은 `ba058ca`이며 앞선 시뮬레이션의 미커밋 변경을 보존했다. 변경 전 관련 파일은 gitignore된 `.local/vi-entry-followup-baseline-20260930/`에 복사해 후속 수정과 구별한다.

사용자가 표시를 확인한 뒤 **push·배포를 명시 승인**했다. 검수 후 `master`에 반영하며 실제 배포 결과는 [I007](I007-github-pages.md)에 기록한다.
