# I004 · 하네스 개발·독립 검수 루프

기준일: 2026-09-30 · 현재 상태: **로컬 구현·자동 검사·독립 검수 완료 / MVP 실기·전문가 수용 대기**

## 목표와 승인

사용자가 최초 commit·master push·외부 티켓 발행을 승인하고, 하네스팀을 동원한 개발과 별도 검수 TEAM AGENT를 요청했다. 기존 문서 전용 범위는 이 요청으로 제품 개발까지 확장됐다. 배포·유료 의뢰·외부 모집은 포함하지 않는다.

목표는 로그인 없는 로컬 개발 미리보기에서 3언어 설정 → 자모/단어/문장 입력 → 카페 의미 선택 → 분리 결과 → 진도·복습을 작동시키고 독립 검수 지적을 수정하는 것이다. 실제 OS 입력기 검증과 전문가 언어 검수는 별도 수용 근거로 남긴다.

- preset: default. 입력/프라이버시/권리 경계와 독립 검수 포함.
- baseCommit: 01288d88d412a81a41bb76650901df58cbfc6253 (개발 시작 직전 문서 최초 커밋, 작업 트리 clean).
- constraints: master 사용, 다른 프로젝트·전역 설정 미변경, 비공개 유지, 고정 범위 staging, 명시 승인 없는 외부 서비스/모집/유료 작업 없음.

## 검증 상태

### 구현 결과

- React·TypeScript·Vite로 로그인 없는 로컬 앱을 만들었다. UI 언어와 연습 언어를 각각 ko/en/vi로 선택한다.
- 자모·단어·생활 문장·카페 주문 흐름, 하단 한국어/영어/베트남어 해석, 타자·의미의 분리 결과를 구현했다. 카페 기본 모드는 시간 제한이 없다.
- 복습 준비에서 해석을 숨겨 시작할 수 있고 같은 방문에서 이미 본 해석은 노출 기록을 유지한다. 첫 답과 재시도, 개인 CPM 표시와 비교 자격을 구분한다.
- 완료 진도·복습 큐·이어하기·단일 앱 키 삭제, 저장 손상·미래 버전·쓰기 실패·다중 탭 변경 보호를 구현했다. 원시 입력은 장기 저장하지 않는다.
- 초안은 20개 개념 × 3언어 = 60개 변형이다. 검수 지적 수정으로 각 개념은 revision 2이며 모든 교육/언어/권리 상태는 draft다. 이미지·오디오 참조는 null이다.
- 개발 서버는 초안 미리보기 안내를 표시한다. 기본 제공 모드는 승인 문항만 읽으므로 현재 release 목록은 0개다. 일부 문항만 승인되면 이용 가능한 첫 단계로 시작하도록 검사했다.

### 베트남어 지원의 의미

**베트남어 화면·학습 문구·성조를 보존하는 입력/채점 기능은 구현했다. 실제 Windows Telex/VNI 입력기 호환성은 확인 대기다.** 사용자 언어 목록에서 ko/en-US만 확인했다는 사실로 모든 입력기의 설치 여부나 베트남어 기능 미지원을 단정하지 않는다. 문자열을 주입한 자동 검사는 실제 Telex/VNI 키열·후보창 동작을 검증하지 못한다.

한글 조합 종료 후 첫 활성화로 최종 DOM 값을 확인하고 다음 별도 활성화에서 제출하는 보수적인 임시 정책을 사용한다. 실제 입력기 관찰 뒤 사용성과 호환성을 함께 검토해야 한다.

### 티켓·원격 반영과 다음 단계

- 로컬 [티켓](tickets/INDEX.md)과 MAIHANGUL Kanban에 20개 ID·링크·상태를 반영했다. MH-003/004는 로컬 Done, 17개는 남은 수용 조건 때문에 Blocked, MH-020은 Backlog다.
- Blocked는 구현 부재 표시가 아니다. 구현/자동 검사 결과는 각 티켓의 `실행 결과`, 실제 환경 수용 조건은 기존 수용 기준에 따로 적었다.
- GitHub 비공개 저장소·master 기본 브랜치·문서 최초 push·Issue 20건 발행은 완료했다. 원격 Issue는 재조회 시 모두 OPEN이다. **이번 제품 구현·검수 수정분은 로컬 작업 트리에 있으며 후속 commit/push·원격 Issue 종료는 실행하지 않았다.** 최초 문서 커밋과 제품 코드 게시를 혼동하지 않는다.
- 다음 우선순위는 MH-001/002 실제 입력기 관찰, MH-006/014 실제 브라우저·키보드 확인, MH-005 최소 3개 문항 전문가 검수다. 이후 MH-016/017 통합 실기와 MH-018 전체 검수 근거를 모아 MH-019를 수용한다.
- `benchmarks/baseline.json`은 scaffold·빈 metrics·benchmark_date null을 유지한다. 설명만 실제 실행 범위에 맞춰 갱신했으며 타자 성능·학습 효과를 측정했다고 기록하지 않았다.

로컬 개발 루프의 자동 검사 완료와 제품 MVP 수용을 구분한다. 실제 브라우저·입력기·전문가 필수 게이트가 남아 있으므로 전체 MVP PASS 또는 정식 제공 완료를 선언하지 않는다.
