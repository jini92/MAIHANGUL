# A001 · MAIHANGUL 요구사항

상태: **상세 설계 Draft / 로컬 구현·검수 기록 연결** · 최초 작성: 2026-09-29 · 갱신: 2026-09-30

구현·검증의 현재 근거는 [I004](I004-harness-development.md)를 따른다. 요구사항 작성과 MVP 수용은 별도다.

이번 승인 범위는 상세 설계, 개발 티켓, 로컬 Kanban이다. 제품 요구사항 정본은 이 문서, 실행 순서와 추적표는 [I002](I002-development-plan.md)다.

## 1. 목적과 대상

베트남 학습자가 한글 자판과 문장의 뜻을 함께 익히고 독자적인 카페 게임으로 복습하게 한다. **타자 정확도·속도와 의미 이해를 별도로 측정**한다.

첫 대상은 PC를 사용하는 베트남어 모어 성인 한국어 초급자라는 **검증 전 가정**이다. 연령·기기·수준·자판 경험은 [T001](T001-validation-plan.md)의 사용자 탐색에서 확인한다. MAIHANGUL은 내부 작업명이며 상표·도메인 사용 가능성은 미확인이다.

## 2. 요구사항 ID

R01~R05는 초기 PRD 식별자를 유지한다. R05는 초기화 이력이며 제품의 미완료 기능으로 다시 계산하지 않는다. R06 이후는 구현·검증 단위로 보완한 요구다.

| ID | 확정 요구 | 관찰 가능한 완료 기준 |
|---|---|---|
| R01 | 한글·한국어 학습과 타자 연습 | 자모·자판 → 단어 → 생활 문장 → 카페 → 오답 복습 완료 |
| R02 | 한국어·영어·베트남어 UI·학습 문구·입력 | 메뉴·오류·도움말 3언어 표시, 각 언어 연습 입력 제출 |
| R03 | 문제 아래 해석, 기본 표시 | 한국어 풀이·영어·베트남어 해석 모두 표시, 복습에서만 사용자가 숨김/펼침 |
| R04 | 독자 UI·게임·콘텐츠와 권리 관리 | 공개 대상마다 출처·권리·검수 근거, 미확인 자산 배제 |
| R05 | 초기화·작업명·로컬 구조 | [I001](I001-initialization.md)의 과거 기록 보존과 현 상태 대조 |
| R06 | UI 언어·연습 언어·해석 표시 분리 | UI 전환으로 입력·점수 초기화 없음, 연습 언어 전환은 중단 확인 후 새 시도 |
| R07 | 한글 IME 안전 처리 | 조합 중 오답·제출 없음, 확정 Enter 중복 제출 없음, 취소·삭제·전환 후 오래된 이벤트 무시 |
| R08 | 다국어 확정 문자열 비교 | NFC 동등 문자열은 같고 성조 차이는 다르게 채점, Telex/VNI 실기 근거 |
| R09 | 지표 분리·비교 조건 | 최종 문자열 정확도·분당 문자 수·의미 첫 선택 분리, 환경 간 통합 순위 없음 |
| R10 | 독자 카페 주문 게임 | 문장 입력 → 뜻에 맞는 주문/사물 선택 → 두 결과 표시, 기본 시간제한 없음 |
| R11 | 오류 유형별 복습 | 입력 오류·의미 오류·둘 다 구분, 첫 결과와 재시도 구분 |
| R12 | 로그인 없는 로컬 진도 | 새로고침 후 완료 진도 읽기, 저장 실패 안내, 앱 데이터만 삭제 |
| R13 | 키보드·시각·읽기 접근성 | 키보드 전 흐름 완료, 보이는 포커스, 색상 외 피드백, 확대·스크린리더 검사 |
| R14 | 선택적 오디오와 실패 대응 | 허가·검수된 음성만 재생, 부재·실패 시 텍스트 학습 지속 |
| R15 | 개인정보 최소화 | 계정·분석 전송·원시 입력 저장 없이 로컬 집계, 보존·삭제 안내 |
| R16 | 자체 제작 20개 개념과 검수 | 20개 개념의 한국어 교육·영어·베트남어 문구·정답·권리 검수 기록 |
| R17 | 중단·재개 | 같은 탭은 마지막 확정 문자열 재개, 새로고침은 미완료 문제 재시작, 점수 중복 없음 |
| R18 | 누락·오류 콘텐츠 차단 | 번역·정답·권리·버전이 불완전한 문항 제외, 빈 목록 안내 |
| R19 | 진도와 단계 이동 | 단계 잠금 없이 권장 순서·직접 선택·이어하기와 완료 표시 |

## 3. MVP 사용자 흐름

1. 가입 없이 시작한다. 첫 UI는 베트남어를 제안하고 즉시 한국어·영어로 전환할 수 있다.
2. 기본 연습 언어는 한국어다. 자모·자판 안내 → 단어 → 생활 문장으로 진행한다.
3. 명시적으로 입력을 제출한 뒤 결과를 확인한다. 틀리면 재입력하거나 입력 실패를 기록하고 의미 선택으로 진행한다.
4. 카페에서 뜻에 맞는 텍스트 사물/주문 카드를 선택한다. 속도에 따른 탈락은 없다.
5. 결과에서 첫 시도·재시도, 힌트 노출, 저장 상태를 확인하고 다음 문제 또는 복습으로 간다.
6. 풀이·해석은 문제 아래 기본 표시한다. 복습 준비 화면에서 문항을 보기 전에 숨김 시작을 직접 선택할 수 있다. 이미 해석을 본 뒤 숨기거나 같은 복습 방문에서 바로 재시작해도 해당 문항의 `hintExposed`를 되돌리지 않는다.

영어·베트남어는 같은 20개 개념의 짧은 연습 변형으로 제공한다. 자모 개념의 영어·베트남어 변형은 검수된 글자 이름/설명 문구 연습이다. 독립적인 전체 교육과정은 후속이지만 **세 언어의 UI·입력·문구·해석·채점은 MVP 범위**다. 개념 구성과 필드는 [D004](D004-content-data-rights.md)가 정본이다.

완료는 제출·선택 수행을 뜻하며 숙달과 같지 않다. 의미 선택이 없는 자모 문항의 의미 점수는 `null`이다. 의미 결과에는 힌트 노출을 함께 표시한다.

## 4. 가정과 설계 선택

| 항목 | 현재 선택과 근거 | 확인 시점 |
|---|---|---|
| 사용자 | PC의 베트남어권 성인 한국어 초급자 | MH-020 탐색; 모집은 별도 승인 |
| 운영 | 서버·계정 없이 로컬 진도 | MH-011/017 저장·실패 검증 |
| 스택 | React + TypeScript + Vite; 상태 화면·3언어 관리 | MH-006 버전·런타임 확인 |
| 환경 | Windows 11 PC의 Chrome·Edge 우선 | MH-001/002/016 실제 환경 기록 후 지원 판단 |
| 평가 | 확정 후 명시 제출, NFC 및 제한적 공백 정리 | D003·MH-008/016 |
| 분량 | 20개 개념, 최소 3개 먼저 검수 | MH-005 최소 검수, MH-018 전체 검수 |
| 오디오 | 선택 기능, 초기 비활성 | MH-013 부재·실패 흐름; 자산 권리 확보 전 텍스트 |

이는 진행 가능한 로컬 설계 선택이다. 설치·브라우저 지원·학습 효과가 확인됐다는 뜻이 아니다.

## 5. MVP 완료 기준

- R01~R04와 R06~R19의 구현·검증 근거가 [추적표](I002-development-plan.md)에 연결된다.
- 한국어 중심 전 흐름과 영어·베트남어 짧은 연습을 3개 UI 언어에서 완료한다.
- 실제 Windows 한국어 IME·Telex·VNI × Chrome·Edge 검사에 미해결 필수 실패가 없다. 합성 이벤트로 대체하지 않는다.
- 자체 제작 20개 개념의 세 언어 문구·교육·권리 검수를 완료한다. 초안은 개발 미리보기만 허용한다.
- 저장·음성 실패, 키보드, 중단·재개, 콘텐츠 누락을 검사한다.
- MH-019에 근거·잔여 문제·지원 환경을 묶는다. 로컬 기술 MVP 수용이며 외부 공개 승인은 별도다.
- MH-020 사용자 탐색은 후속 평가다. 기술 MVP 완료를 학습 효과 입증으로 표현하지 않는다.

## 6. 후속 범위와 권리

영어·베트남어 독립 교육과정, 모바일 전용 UX, 실시간 대전, AI 대화, 교사 관리, 계정·동기화·결제, 속도 도전, 30~50문항 확장은 MVP 검증 뒤 검토한다. MAITUTOR·MAISTUDYMATE 연계는 후보이며 현재 연동은 없다.

한컴타자는 초기 기능 분석의 참고 서비스다. 코드·화면·캐릭터·문항·음원·이미지를 복제하지 않는다. 공개 자료도 개별 이용 조건 없이 제품에 넣지 않는다. [권리 장부](../content/ASSET-LICENSES.md) 작성만으로 무침해나 권리 확보를 확정하지 않는다.
